# GLPI

**GLPI** (Gestionnaire Libre de Parc Informatique) est un outil open source de gestion d'inventaire et de tickets d'incident.

## Fonctionnalités

- **Inventaire** : remontée automatique des composants des postes de travail
- **Gestion des tickets** : suivi des incidents et demandes d'assistance
- **Base de connaissances** : documentation des procédures
